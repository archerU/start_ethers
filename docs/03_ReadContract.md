# 03_ReadContract.js - 智能合约读取示例

## 功能描述
演示如何读取智能合约的数据，包括ERC20代币余额查询、合约状态读取等操作。

## 主要功能
- 连接ERC20代币合约
- 查询代币余额
- 读取合约基本信息
- 查询代币符号和精度
- 获取合约事件日志

## 技术要点
- 使用Contract类创建合约实例
- 调用合约的view/pure函数
- 使用ethers.getContract()创建合约
- 处理合约调用结果
- 错误处理和异常捕获
