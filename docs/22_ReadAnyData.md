# 22_ReadAnyData.js - 读取任意数据

## 功能描述
演示如何读取合约存储槽（Storage Slot）中的任意数据，绕过公开接口直接读取底层数据。

## 主要功能
- 读取特定存储槽的数据
- 解析存储槽中的地址
- 访问合约私有变量
- 理解存储布局

## 技术要点
- 使用`provider.getStorage()`读取存储槽
- 计算存储槽位置
- 使用`ethers.dataSlice()`提取数据
- 使用`ethers.getAddress()`格式化地址

## 输出信息
- 存储槽位置
- 读取的原始数据
- 解析后的地址
- 数据格式

## 使用方法
1. 创建Provider连接到网络
2. 确定目标存储槽位置
3. 使用getStorage读取数据
4. 解析数据格式
5. 显示解析结果

## 注意事项
- 存储槽位置需要计算正确
- 数据格式需要正确解析
- 私有变量可以读取
- 需要理解存储布局
