# 00_config.js - 配置文件使用示例

## 功能描述
演示如何使用privateKeys.js配置文件中的各种配置项，包括钱包、网络、合约和Gas配置。

## 主要功能
- 加载配置文件
- 创建钱包实例
- 连接网络Provider
- 查询钱包余额
- 显示网络信息

## 使用方法
1. 确保privateKeys.js文件已正确配置
2. 运行此文件查看配置使用示例
3. 查看控制台输出了解各种配置的用法

## 配置项说明
- **WALLETS**: 钱包配置（私钥+地址）
- **NETWORKS**: 网络配置（RPC URL + Chain ID）
- **CONTRACTS**: 合约地址配置
- **GAS_CONFIG**: Gas费用配置
- **ADDRESSES**: 常用地址配置

## 注意事项
- 私钥信息敏感，请勿提交到代码仓库
- 测试网和主网使用不同的配置
- Gas费用根据网络拥堵情况调整
