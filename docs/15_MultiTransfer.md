# 15_MultiTransfer.js - 批量转账

## 功能描述
演示如何使用HD钱包进行批量转账操作，向多个地址发送ETH或代币。

## 主要功能
- 从HD钱包派生多个地址
- 批量发送ETH到多个地址
- 批量发送代币到多个地址
- 处理批量交易

## 技术要点
- 使用HD钱包派生地址列表
- 循环发送交易到多个地址
- 处理交易状态和错误
- 优化gas费用设置

## 输出信息
- 接收地址列表
- 转账金额
- 交易哈希列表
- 交易状态和确认

## 使用方法
1. 创建HD钱包
2. 派生多个接收地址
3. 准备转账金额数组
4. 循环发送交易
5. 等待交易确认

## 注意事项
- 需要足够的余额支付gas
- 批量交易可能耗时长
- 需要处理交易失败情况
- 注意gas limit设置
