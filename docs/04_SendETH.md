# 04_SendETH.js - 发送ETH示例

## 功能描述
演示如何使用ethers.js发送ETH交易，包括创建钱包、构建交易、发送交易等完整流程。

## 主要功能
- 创建钱包实例
- 构建ETH转账交易
- 估算Gas费用
- 发送交易到网络
- 等待交易确认
- 查询交易状态

## 技术要点
- 使用Wallet类创建钱包
- 构建交易对象（to, value, gasLimit等）
- 使用wallet.sendTransaction()发送交易
- 使用provider.waitForTransaction()等待确认
- 交易状态查询和错误处理

## 交易参数
- **发送方**: 配置的钱包地址
- **接收方**: 目标地址
- **金额**: ETH数量
- **Gas限制**: 21000（基础转账）
- **Gas价格**: 根据网络状况动态设置

## 输出信息
- 交易哈希
- 交易状态
- Gas使用情况
- 交易确认信息
- 余额变化

## 学习价值
- 学习ETH转账操作
- 掌握交易构建流程
- 理解Gas费用机制
- 学习交易确认等待
- 掌握钱包操作
