# 24_ERC20Check.js - ERC20标准检查

## 功能描述
演示如何通过检查合约字节码来判断合约是否符合ERC20标准，不依赖ABI接口。

## 主要功能
- 检查合约字节码
- 识别ERC20函数选择器
- 判断合约标准兼容性
- 区分合约和普通地址

## 技术要点
- 使用`provider.getCode()`获取字节码
- 检查字节码中的函数选择器
- transfer选择器：0xa9059cbb
- totalSupply选择器：0x18160ddd

## 输出信息
- 合约地址
- 是否为合约
- 是否为ERC20标准
- 检查结果

## 使用方法
1. 创建Provider连接到网络
2. 获取合约字节码
3. 检查函数选择器
4. 判断标准兼容性
5. 输出检查结果

## 注意事项
- 字节码必须包含函数选择器
- 选择器必须完整匹配
- 非合约地址返回0x
- 检查方法不可靠但实用
