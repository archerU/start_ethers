# 21_VanityAddress.js - 靓号地址

## 功能描述
演示如何生成具有特定前缀或后缀的以太坊地址（靓号地址）。

## 主要功能
- 生成随机地址
- 检查地址格式
- 筛选特定格式地址
- 保存符合条件的地址

## 技术要点
- 循环生成随机私钥
- 从私钥生成地址
- 检查地址格式
- 保存匹配的地址和私钥

## 输出信息
- 生成的地址
- 匹配规则
- 找到的靓号地址
- 对应的私钥

## 使用方法
1. 设置目标地址格式
2. 循环生成随机地址
3. 检查地址格式
4. 保存匹配结果

## 注意事项
- 生成靓号地址耗时较长
- 私钥需要安全保存
- 地址格式限制越多越难找
- 计算资源消耗较大
