# 02_Provider.js - Provider功能全面示例

## 功能描述
全面展示ethers.js Provider的各种功能，包括网络连接、区块查询、余额查询、Gas费用等。

## 主要功能
- 连接多个网络（主网、测试网）
- 查询区块信息
- 查询账户余额
- 获取Gas费用信息
- 网络状态检查

## 技术要点
- 多网络Provider配置
- 区块数据查询（getBlock, getBlockNumber）
- 余额查询（getBalance）
- Gas费用查询（getFeeData）
- 网络信息获取（getNetwork）
- 错误处理和网络状态检查

## 输出信息
- 网络连接状态
- 当前区块信息
- 账户余额详情
- Gas费用数据
- 网络基本信息

## 学习价值
- 深入理解Provider的功能
- 学习多网络开发
- 掌握区块和交易数据查询
- 了解Gas费用机制
- 学习网络状态监控
