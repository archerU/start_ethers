# 16_MultiCollect.js - 批量收集

## 功能描述
演示如何从多个地址收集资金到主钱包，包括ETH和代币的批量收集。

## 主要功能
- 从多个地址收集ETH
- 从多个地址收集代币
- 批量处理收集交易
- 汇总到主钱包

## 技术要点
- 使用HD钱包获取多个地址
- 检查每个地址的余额
- 发送收集交易
- 处理gas费用问题

## 输出信息
- 源地址列表
- 收集的金额
- 交易哈希
- 收集后的总余额

## 使用方法
1. 创建主钱包和HD钱包
2. 获取需要收集的地址列表
3. 检查每个地址余额
4. 发送收集交易
5. 确认收集结果

## 注意事项
- 需要保留gas费用
- 空地址可以跳过
- 收集需要支付gas
- 注意余额检查
