# 12_ERC721Check.js - ERC721标准检查

## 功能描述
演示如何检查合约是否符合ERC721标准，使用ERC165的supportsInterface方法。

## 主要功能
- 读取ERC721合约基本信息
- 使用ERC165检查标准兼容性
- 验证合约接口支持
- 显示合约名称和符号

## 技术要点
- 使用`contract.supportsInterface()`检查接口支持
- ERC721接口标识符：0x80ac58cd
- 读取合约name和symbol
- ERC165标准接口检查

## 输出信息
- 合约地址
- 合约名称和符号
- 是否为ERC721标准
- 接口支持状态

## 使用方法
1. 创建Provider连接到网络
2. 创建合约实例
3. 读取合约基本信息
4. 使用supportsInterface检查标准
5. 显示检查结果

## 注意事项
- 需要合约实现ERC165标准
- 接口标识符必须正确
- 如果合约不支持会报错
- 检查结果需要验证
