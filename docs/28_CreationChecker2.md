# 28_CreationChecker2.js - 合约创建检测2

## 功能描述
演示如何使用debug_traceBlockByNumber RPC方法追踪区块中的合约创建，更详细地检测合约创建。

## 主要功能
- 使用RPC调试接口
- 追踪区块中的合约创建
- 分析调用追踪
- 识别CREATE操作码

## 技术要点
- 使用`debug_traceBlockByNumber`RPC方法
- 分析追踪结果
- 查找CREATE操作码
- 提取合约地址

## 输出信息
- 区块中的合约创建
- 调用追踪详情
- 合约创建地址
- 创建者地址

## 使用方法
1. 调用RPC调试接口
2. 获取区块追踪数据
3. 分析追踪结果
4. 识别合约创建
5. 提取相关信息

## 注意事项
- 需要支持debug接口的RPC
- 追踪数据量大
- 分析可能复杂
- 性能消耗较高
