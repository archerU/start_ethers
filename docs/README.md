# 文档目录

本目录包含所有示例文件的说明文档。

## 文档结构

- `00_config.md` - 配置文件使用示例
- `01_helloVitalik.md` - Hello Vitalik示例
- `02_Provider.md` - Provider功能全面示例
- `03_ReadContract.md` - 智能合约读取示例
- `04_SendETH.md` - 发送ETH示例
- `05_WriteContract.md` - 智能合约写入示例

## 文档说明

每个文档都包含以下内容：
- 功能描述
- 主要功能
- 技术要点
- 输出信息
- 学习价值

## 使用方法

在web界面中选择对应的示例文件，右侧会自动显示对应的说明文档。

## 更新说明

如需更新文档，请直接编辑对应的.md文件，web界面会自动加载最新内容。
