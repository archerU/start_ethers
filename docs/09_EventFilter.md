# 09_EventFilter.js - 事件过滤

## 功能描述
演示如何使用事件过滤器监听特定条件的合约事件，如监听特定地址的转账。

## 主要功能
- 创建事件过滤器
- 过滤特定发送方的事件
- 过滤特定接收方的事件
- 实时监听过滤后的事件

## 技术要点
- 使用`contract.filters.Transfer()`创建过滤器
- 过滤条件设置（from, to）
- 监听过滤后的事件
- 解析事件参数

## 输出信息
- 过滤器详情
- 符合条件的转账事件
- 事件参数（from, to, value）
- 格式化的转账金额

## 使用方法
1. 创建Provider和合约实例
2. 使用filters创建过滤器
3. 设置过滤条件（地址）
4. 监听过滤后的事件
5. 处理并显示事件数据

## 注意事项
- 过滤器条件需要正确设置
- null表示不限制该字段
- 多个过滤条件可以组合使用
- 过滤后的事件可能仍然很多
