# 18_Signature.js - 数字签名

## 功能描述
演示如何使用ethers.js进行数字签名，包括消息哈希、签名生成和验证，用于NFT白名单验证。

## 主要功能
- 生成消息哈希
- 使用钱包签名消息哈希
- 验证签名有效性
- 部署带签名验证的合约

## 技术要点
- 使用`ethers.solidityPackedKeccak256()`生成消息哈希
- 使用`wallet.signMessage()`签名消息
- 使用`ethers.recoverAddress()`验证签名
- 在合约中验证签名者

## 输出信息
- 消息哈希
- 签名结果
- 签名验证结果
- 签名者地址

## 使用方法
1. 创建Provider和Wallet
2. 准备消息数据
3. 生成消息哈希
4. 使用私钥签名
5. 验证签名有效性

## 注意事项
- 消息格式需要与合约一致
- 签名算法需要匹配
- 私钥需要安全保管
- 合约需要实现签名验证
