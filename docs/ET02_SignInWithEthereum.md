# ET02_SignInWithEthereum.js - 使用以太坊登录

## 功能描述
演示如何使用EIP-4361标准实现"使用以太坊登录"（Sign-In with Ethereum，SIWE）功能。

## 主要功能
- 生成SIWE消息
- 使用钱包签名
- 验证签名
- 实现身份验证

## 技术要点
- 遵循EIP-4361标准
- 使用EIP712或标准消息签名
- 验证签名者地址
- 处理时间戳和nonce

## 输出信息
- SIWE消息
- 签名结果
- 验证结果
- 签名者地址

## 使用方法
1. 生成SIWE消息
2. 使用钱包签名
3. 发送到服务器验证
4. 完成身份验证

## 注意事项
- 需要遵循EIP-4361标准
- 消息格式需要正确
- 时间戳需要验证
- nonce需要管理
