# 07_Event.js - 监听智能合约事件

## 功能描述
演示如何查询和解析智能合约的历史事件数据。

## 主要功能
- 查询指定区块范围内的合约事件
- 解析事件参数和数据
- 过滤特定类型的事件
- 获取事件的详细信息

## 技术要点
- 使用`contract.queryFilter()`查询事件
- 指定区块范围进行查询
- 解析事件的args参数
- 使用ethers格式化事件数据

## 输出信息
- 查询到的事件列表
- 事件参数（from, to, amount等）
- 格式化后的事件数据
- 区块高度信息

## 使用方法
1. 创建Provider连接到网络
2. 创建合约实例
3. 使用queryFilter()查询事件
4. 解析事件的args参数
5. 格式化并显示事件数据

## 注意事项
- 查询大范围区块可能耗时较长
- 需要确保合约地址和ABI正确
- 事件参数顺序需要与ABI匹配
