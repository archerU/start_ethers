# 08_ContractListener.js - 合约监听

## 功能描述
演示如何实时监听智能合约的事件，包括一次性监听和持续监听。

## 主要功能
- 使用`contract.once()`监听一次事件
- 使用`contract.on()`持续监听事件
- 实时接收合约事件通知
- 处理事件数据并格式化输出

## 技术要点
- 使用`contract.once()`监听单次事件
- 使用`contract.on()`持续监听
- 事件回调函数处理
- 使用ethers格式化单位

## 输出信息
- 监听的事件类型
- 事件参数（from, to, value）
- 格式化的交易金额
- 实时事件通知

## 使用方法
1. 创建Provider连接到网络
2. 创建合约实例
3. 使用once()或on()监听事件
4. 在回调函数中处理事件数据
5. 格式化并输出事件信息

## 注意事项
- 持续监听会一直运行直到停止
- 需要保持连接稳定
- 大量事件可能影响性能
- 使用once()可以避免内存泄漏
