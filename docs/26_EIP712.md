# 26_EIP712.js - EIP712签名

## 功能描述
演示如何使用EIP712标准进行结构化数据签名，提供更好的签名体验和安全性。

## 主要功能
- 创建EIP712 Domain
- 定义类型化数据结构
- 生成EIP712签名
- 验证签名有效性

## 技术要点
- 使用`wallet.signTypedData()`签名
- 使用`ethers.verifyTypedData()`验证
- 定义domain和types
- 创建message结构

## 输出信息
- 消息内容
- EIP712签名
- 签名者地址
- 验证结果

## 使用方法
1. 创建EIP712 Domain
2. 定义类型化数据结构
3. 创建消息对象
4. 使用signTypedData签名
5. 验证签名

## 注意事项
- Domain参数需要正确设置
- Types定义需要匹配合约
- 链ID需要正确
- 消息格式需要一致
